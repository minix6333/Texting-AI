# Texting-AI：注音 AI 輸入法（macOS／Windows）

打字時由**本機**的小型 LLM（Qwen3-0.6B）即時修正錯字的輸入法。支援繁體中文（注音，大千鍵盤）與英文，不連網、不上傳任何文字。

- **macOS 版**（`mac/`）：Swift + InputMethodKit，按鍵照 macOS 內建「注音－繁體」。已在 Mac 上實際安裝使用與測試。
- **Windows 版**（`windows/`）：C++，TSF 文字服務（64／32 位元 DLL）＋ 每位使用者一個引擎伺服器。按鍵照「微軟注音」。核心是 Mac 版引擎逐行移植，兩邊準確率一致（見下表）。在 macOS 上交叉編譯並測過引擎與按鍵邏輯，GitHub Actions 在 Windows 上建置並測試；**還沒有在實體 Windows 電腦上手動打字測試過**。

## 怎麼運作

1. **按鍵不等 AI。** 注音組字與詞庫轉換（libchewing 詞庫，K-best lattice）每鍵 1 毫秒內完成，畫面立刻出字。
2. **AI 從候選裡挑最合理的一句。** 每完成一個音節，LLM 在背景替 8 個候選句打分（上文取自游標前約 300 字），再和打錯鍵的機率、詞頻合併計分。打錯鄰近鍵、聲調、ㄣ/ㄥ、ㄓ/ㄗ 等口音混淆都會列入候選，但要「明顯比較合理」才會改你打的字。
3. **標記與跳轉。** AI 改過的字畫橘色粗底線；AI 沒改、但覺得可能有錯的字畫紅色（Windows 是紅色波浪線）。按 **Tab／Shift+Tab** 直接跳到下一個／上一個被標記的字，選字窗同時打開，第一個是現在顯示的字、接著是 AI 的建議。游標移進句子時，游標所在的字會一直標示出來（Mac 用游標旁的小提示框，Windows 另外把那個字反白）。
4. **英文拼字修正。** 每打一個字母就先在背景檢查，打到空白或標點時通常已經有答案，在邊界字元出現前就改好（例如 teh → the、recieved → received、dont → don't）。字典裡的字、專有名詞、文件裡出現過的字都不改。改完緊接著按 Backspace（Mac 是 Delete）會還原，而且記住這個字以後不再改。
5. **中／英模式全域共用。** 單按 Shift 切換中／英；切到別的視窗或 App 還是同一個模式，切回來也一樣（Mac、Windows 都是）。

## 準確度（同一份測試資料）

中文：138 句、1,563 字，每句含一個打錯的注音（`bench/zh_candidates.json`）。

| | 有錯字：字 | 有錯字：整句 | 乾淨輸入：字 | 乾淨輸入：整句 |
|---|---|---|---|---|
| 只用詞庫 | — | 52.2% | — | 66.7% |
| macOS（Swift） | 96.93% | 73.9% | 98.66% | 89.1% |
| Windows 引擎（C++） | 96.99% | 74.6% | 98.59% | 88.4% |

可疑字標記（門檻 0.70）：有錯字的句子裡，AI 沒改的 27 個錯字抓到 11 個，誤標率 0.8%。

英文：1,090 個字（真人拼錯 540、打錯鍵 300、不該改的字 250），兩個版本結果相同。

| 類型 | 改對 | 改錯 | 不該改卻改了 |
|---|---|---|---|
| 真人拼錯（Norvig／Birkbeck） | 87.8% | 5.9% | — |
| 打錯鍵 | 98.0% | 2.0% | — |
| 正確但不在字典的字 | — | — | 4.0% |

延遲：Mac（M4，Metal）每音節 LLM p50 約 23–34 ms；英文每字 p50 約 13 ms。Windows 版用 CPU（AVX2）推論，會比 Mac 慢，實際數字要在 Windows 電腦上量。

## 目錄

```
mac/       macOS 輸入法（Swift Package；build_app.sh、install.sh）
windows/   Windows 版：core/ 引擎、engine/ LLM 與按鍵邏輯、server/ 引擎伺服器、tsf/ 文字服務、installer/
data/      兩個平台共用的詞庫與英文資料
bench/     評測資料與產生腳本
docs/      設計報告與研究筆記
```

各平台的建置、安裝與完整按鍵表：[mac/README.md](mac/README.md)、[windows/README.md](windows/README.md)。

## 隱私

上文只在本機的輸入法／引擎程序裡使用；紀錄檔只記事件與延遲數字，從不記錄打的文字。模型在安裝時下載到本機，之後完全離線。
