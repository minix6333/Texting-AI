# 注音 AI（ZhuyinLLM）macOS 版

macOS 輸入法，打字時由本機小型 LLM 即時修正錯字。支援繁體中文（注音，大千鍵盤）與英文，按鍵照 macOS 內建的「注音－繁體」。LLM（Qwen3-0.6B）在本機執行，不連網。

## 怎麼運作

- **按鍵不等 LLM。** 注音組字和詞庫轉換（libchewing 詞庫、K-best lattice）每鍵 1 毫秒內完成，畫面立刻出字。
- **LLM 負責挑最合理的一句。** 每打完一個音節，Qwen3-0.6B（llama.cpp，Metal）在背景替 8 個候選句打分。上文取自你正在編輯的文件，游標前約 300 字。
- **容錯。** 打錯鄰近鍵、按錯聲調、ㄣ/ㄥ、ㄓ/ㄗ 這類口音混淆都會列入候選，但要明顯比較合理才會改你打的字；只打一個音節時不改。
- **標記。** AI 改過的字畫**橘色粗底線**；AI 沒改、但覺得可能有錯的字畫**紅色點狀底線**。
- **游標提示框。** 在句子裡移動游標時，游標前的字會在旁邊的小框裡顯示它的字和讀音；如果 AI 改過或懷疑它，框裡也會說明。（「文字編輯」這類 App 不會在組字區裡畫選取範圍，所以用提示框讓你一直知道自己在哪個字。）
- **英文模式。** 單按 Shift 切換。按鍵直接交給 App（dead key、長按出重音字母都和 ABC 一樣）。每打一個字母就先在背景檢查，打到空白、標點、Return 或 Tab 時通常已有答案，在邊界字元出現前就改好，例如 teh → the、recieved → received、dont → don't、i → I。字典裡的字、專有名詞、文件裡出現過的字都不改。改之前會先確認文件裡的字和你打的一樣；改完緊接著按 Delete 會還原，並記住這個字以後不再改。
- **中／英模式全域共用。** 切到別的視窗或 App 時維持原本的中／英；切回來也一樣。（中文與英文都在「注音 AI」這一個輸入方式裡，所以即使「自動切換至文件的輸入方式」是開著的，也不會被系統換掉。）

## 按鍵

| 按鍵 | 行為 |
|---|---|
| 注音鍵、6 3 4 7、空白 | 組字；聲調鍵或空白（一聲）完成一個音節 |
| 空白（已轉換後）、↓ | 開選字窗；選字窗中每按一次空白（或 ↓ →）換下一個字，文字跟著變 |
| Return／數字 1–9 | 送出；選字窗中是選定這個字 |
| ↑ ←、= -、[ ]、PageUp PageDown | 選字窗中換上一個字、換頁；組字時 ← → 移動游標 |
| Esc（選字窗中） | 關掉選字窗，恢復原本的字（AI 標記保留） |
| **Tab／⇧Tab** | 跳到下一個／上一個 AI 標記的字並打開選字窗：第一個是現在的字，接著是 AI 的建議。選字窗中按 Tab 跳到下一個標記 |
| ⇧Delete | 先把 AI 改過的字退回你實際打的（之後也不會再改回去） |
| Esc | 清掉正在打的音節，再按一次清掉整段 |
| **單按 Shift** | 切換中／英（游標旁會閃一下「中」或「英」） |
| ⌥＋數字 | 輸入數字 |
| ⇧, ⇧. [ ] ⇧[ ⇧] \ | ， 。 「 」 『 』 、 |
| ⌘、⌃ 組合 | 先送出，再交給 App |

選單列的「注音 AI」選單：英文模式（AI 拼字修正）、單按 Shift 切換中／英、AI 即時糾錯、注音打錯鍵容錯。

## 建置與安裝

需要 Homebrew 的 llama.cpp（`brew install llama.cpp`），以及 Qwen3-0.6B Q4_K_M GGUF（Hugging Face 的 unsloth/Qwen3-0.6B-GGUF；build_app.sh 會從 Hugging Face 快取找）。

```bash
./scripts/build_app.sh     # 產生 build/ZhuyinLLM.app（ad-hoc 簽章）和 build/model.gguf
./scripts/install.sh       # 安裝並向系統註冊
```

install.sh 會：

- 把輸入法放到 `~/Library/Input Methods`（原地更新）。
- 把模型放到 `~/Library/Application Support/ZhuyinLLM/model.gguf`。模型不放在 App 裡，因為 385 MB 的 App 會讓 macOS 對每個新版本的首次啟動檢查多花好幾秒。
- 先把新版本啟動一次，讓系統的安全檢查在安裝時就做完，避免那幾秒內打的字被吃掉。

裝好後要自己啟用：系統設定 → 鍵盤 → 文字輸入 →「編輯…」→ 左下「＋」→ 選「繁體中文」裡的「注音 AI」→「加入」→ 回到清單按「完成」。

舊版本有一個獨立的「English AI」輸入方式，現在英文模式已經併進「注音 AI」（單按 Shift 切換）。如果清單裡還看得到「English AI」，請在同一個地方把它移除。

如果更新後選單列或游標旁的圖示沒有換成新的，登出再登入一次就好（系統會暫存輸入法圖示）。

移除：刪掉 `~/Library/Input Methods/ZhuyinLLM.app` 和 `~/Library/Application Support/ZhuyinLLM`，再到上面同一個地方移除輸入方式。

## 隱私

上文直接讀自你正在編輯的文件，最多游標前約 300 字，只在這台電腦的輸入法程序裡使用。紀錄檔只記事件和延遲，從不記錄文字內容。密碼欄位不會經過輸入法。

## 開發

- `imecli eval <tsi.csv> <model.gguf> <zh_candidates.json> [--clean] [--calibrate]`：準確度與每音節延遲。138 句（1,563 字）：
  - 有錯字：字 96.93%，整句 73.9%（只用詞庫 52.2%）。
  - 乾淨輸入（容錯開著）：字 98.66%，整句 89.1%。
  - 可疑字標記（T=2.0、門檻 0.70）：AI 沒改的 27 個錯字抓到 11 個，誤標率 0.7%。
- `imecli en-eval <tsi.csv> <model.gguf> <en_freq.txt> <en_eval.json>`：英文修正。真人拼錯 87.8% 改對（5.9% 改錯）、打錯鍵 98.0%（2.0%）、正確但不在字典的字 4.0% 被改。
- `imecli keys <tsi.csv> <model.gguf> "<大千鍵序列>" "<左文>"`：看某段注音的候選、LLM 分數、標記與建議。
- 輸入法裡實測（M4 Air）：LLM 每音節 p50 約 34 ms，最慢 55 ms；英文每字 p50 約 13 ms；詞庫轉換 < 1 ms。
- 執行紀錄寫在 `~/Library/Logs/ZhuyinLLM.log`，每 25 步記一次延遲分位數。
